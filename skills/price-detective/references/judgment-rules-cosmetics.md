# judgment-rules-cosmetics.md — 护肤美妆品类判断规则

> ⏱️ **DATA-TIMESTAMP**: 2026-05-29 — 内置规则/价格/政策按此时点;**6 个月内有效**,过期建议 WebSearch 重新验证当前政策。

**作用**:被 `SKILL.md` 的 Step 4(Judge)Read。把抓到的真实数据翻成判断,但**美妆是"框架型"判断**,不是 3C 那种"该买 / 等大促 / 假优惠" 的硬结论。

**核心**:美妆的"好价"完全不能套 3C 的折扣率框架 —— **品牌不打面价折扣,促销靠等量买赠**;**渠道决定 60% 的价格差**(国内官旗 vs 保税仓 vs 海淘);**克单价**才是真正可比维度。

**覆盖范围**:主覆盖**护肤主品类**(雅诗兰黛 / 兰蔻 / SK-II / 资生堂 / 修丽可 / 海蓝之谜 / 赫莲娜 等大牌)。香水 / 彩妆 规则暂缺,触发时走 `non-3c-fallback` 退路。

---

## 1. 维度 A — 克单价(¥/ml 或 ¥/g)

**核心**:不要被"瓶身大小"骗。买 50ml ¥906 vs 100ml ¥1799 — **必须算克单价**才能比。

**计算**:`到手价 ÷ 总容量(含赠品)= 克单价`

**赠品折算**:赠品要按**官方价折算**进总容量,不能白送。例:
- 主品 50ml ¥906 + 赠 15ml 旅行装 → 总 65ml,克单价 ¥13.9/ml
- 主品 50ml ¥906 + 赠 50ml 樱花水(非同款,不入克单价) → 主品克单价仍 ¥18.1/ml,但你多了一瓶水(自己估值)

**克单价的"行情区间"**(护肤精华类大致):

| 类型 | 国内官旗克单价 | 保税仓克单价 | 海淘克单价 |
|---|---|---|---|
| 顶级精华(雅诗兰黛小棕瓶 / 兰蔻小黑瓶) | ¥18-20/ml | ¥5-8/ml | ¥6-10/ml |
| 高端精华(修丽可 CE / SK-II 神仙水) | ¥15-25/ml | ¥6-10/ml | ¥8-12/ml |
| 中端精华(资生堂 / 雪花秀) | ¥6-12/ml | ¥3-6/ml | ¥4-7/ml |
| 大牌面霜(海蓝之谜 / 赫莲娜) | ¥30-100/ml | ¥10-40/ml | ¥15-50/ml |

**实际抓的数据要 override 上表** —— 这是"行情参考",不是硬阈值。

## 2. 维度 B — 渠道差倍数(美妆判断的灵魂)

**核心**:**渠道决定 60% 价格差**。国内官旗 = 100%,保税仓通常 30-40%,海淘 30-50%。这不是"假优惠",是真实的关税 / 进货价 / 售后体系 / 防伪策略带来的差异。

| 渠道 | 价格倍数(相对国内官旗) | 优势 | 风险 |
|---|---|---|---|
| 国内官旗(天猫旗舰 / 京东自营) | 1.0× | 真假货放心、国行售后、中国版定制 | 价高 |
| 国内授权专柜 | 1.0-1.05× | 同上 + 现场试用 | 价高 + 没大促 |
| 京东国际 / 天猫国际(自营保税仓) | 0.4-0.6× | 平台背书、关税进口、便宜 | 售后流程长(寄回保税仓)、非中国版 |
| 京东国际 / 天猫国际(第三方店) | 0.3-0.5× | 便宜 | 真假货风险大、售后差 |
| 个人代购 | 0.3-0.5× | 极便宜 | 真假货风险极大、无售后 |
| 海淘美国官网 / Sephora | 0.4-0.6× | 真品保证 + 转运代收 | 邮费 / 关税 / 配送时间 / 没中文说明 |

**判断**:
- 国内官旗 ¥906 vs 保税仓 ¥280 → **差 3.2 倍**,正常(在 1.0× vs 0.3× 区间)
- 国内官旗 ¥906 vs 拼多多代购 ¥180 → **差 5 倍**,**警惕假货**(超过正常渠道差)
- 用户问"专柜 ¥906 vs 海淘 ¥400 哪个值",答案不是"看价格",而是 "**你接不接受 China-care 缺失 + 中文说明缺失 + 邮期 2-4 周**"

**核实渠道身份**:
- **京东国际是不是自营**?标识 "京东国际自营" / "JD WORLDWIDE"
- **拼多多是不是百亿补贴**?底部红框 / Logo
- **天猫国际是不是直营**?店铺名带"海外旗舰店" + 蓝色 V 标
- 不是 → **真假货风险骤升**,差价 > 60% 时几乎确定有问题

## 2.5. **全球同价品牌例外**

§2 的"渠道差倍数" 假设"海淘 0.4-0.6× 国内官旗"在多数品牌成立,**但不普适**。下列品牌走全球同价策略,**海淘价 + 关税 + 转运费反而 ≥ 国内官旗价**,套用常规渠道差倍数会得出错误结论(e2e 005 T6 暴露)。

### 已知全球同价品牌

| 品牌 | 海淘 vs 国内 | 原因 |
|---|---|---|
| **修丽可**(SkinCeuticals) | **1.0-1.2×**(海淘等价或贵) | 欧莱雅集团全球同价策略 + 高浓度活性成分需特殊运输 |
| **理肤泉**(La Roche-Posay) | 1.0-1.1×(部分系列) | 欧莱雅集团 + 药妆渠道管控严 |
| **薇姿**(Vichy) | 1.0-1.1× | 同上 |
| **倩碧**(Clinique 部分新品) | 1.0-1.1×(新品 6 个月内) | 雅诗兰黛集团对新品做全球同步 |
| **顶级品牌限量款 / 节日限定** | 0.9-1.2×(海淘可能更贵) | 限量发售,海外平台炒价 |

### 判断改写

**模板 — 全球同价品牌**:
> "{品牌}是全球同价品牌,海淘 + 关税 + 转运反而比国内官旗贵 5-20%。**国内官旗就是最优渠道**,不存在海淘省钱空间。
> - 急用就买,不存在'等海淘' 这个选项
> - 不急可等 618 / 双11 加赠小样 / 加凑单优惠券
> - 看到拼多多 < 国内官旗 60% 的,**强烈警惕**(高浓度活性成分有储存条件要求,假货 / 临期 / 储存不当 风险都极高)"

### 怎么识别"是不是全球同价品牌"

- WebSearch "{品牌} 海淘 vs 国内 价格差" → 看攻略站(Extrabux / 北美省钱快报)说法
- WebSearch "{品牌} 国内贵还是国外贵" → 找用户讨论
- 品牌官网公告里有"全球同价" 字样 → 直接是
- 攻略站说"国内日常价已接近美亚官网" → 也是
- 找不到证据 → **不假设**,按 §2 常规渠道差倍数处理,但在输出里标"海淘 vs 国内差倍数本品类待验证"

## 3. 维度 C — 等量买赠折算(美妆促销的灵魂)

**核心**:雅诗兰黛 / 兰蔻 / SK-II 等大牌**几乎不打面价**,促销靠"**买 50ml 送 50ml**" / "**买正装送水乳眼霜全套**"。要正确判断"是不是好价",必须**算赠品折算后的实际克单价**。

**等量买赠折算法**:
1. 列出主品 + 所有赠品的官方等量价
2. 算总价值:主品官方价 + 所有赠品官方价
3. 算实际克单价:`到手价 ÷ 总实际容量(主品 ml + 赠品同款 ml)`
4. **不同款赠品不计入主品克单价**,单独估值(自己用 or 转手)

**实例**(雅诗兰黛官旗 50ml ¥906 + 赠 4 瓶 50ml 樱花水):
- 樱花水官方价大约 ¥350/瓶 × 4 = ¥1400 价值
- 主品克单价仍 ¥906 / 50 = ¥18.1/ml(樱花水不算同款,不并入)
- **但**:你多得了 ¥1400 价值的樱花水,**折算总价值** = ¥906 主品 + ¥1400 樱花水 = ¥2306,实际花 ¥906 = **0.39× 折扣**(看起来巨划算)
- **关键**:你**真的需要樱花水吗**?需要 → 这是好价;不需要 → 樱花水转手 / 闲置 = 实际等于花 ¥906 买 50ml

**判断措辞**:
> "京东自营 ¥906 配赠 4 瓶 50ml 樱花水(官方价值约 ¥1400)。
> - **如果你也用樱花水**:总价值 ¥2306 花 ¥906,折合 0.39× 实际折扣,**好价**
> - **如果你只要小棕瓶,赠品转手 / 闲置**:实际是 ¥906 买 50ml(克单价 ¥18.1/ml),**这是雅诗兰黛国内官旗常态价**,不算特别便宜
> - 看你自己用不用赠品"

## 4. 维度 D — 渠道身份真假货风险

| 渠道 | 真品概率 | 怎么核 |
|---|---|---|
| 品牌天猫官旗 / 京东自营 | ~100% | 标"官方旗舰店" + 蓝 V + 旗舰店认证 |
| 国内授权专柜(线下)| ~100% | 商场内官方专柜,有发票 |
| 京东国际自营保税仓 | ~95% | "京东国际自营" 标识 + 关检证书可查 |
| 天猫国际海外旗舰店 | ~95% | "海外旗舰店" + 进口溯源码 |
| 拼多多百亿补贴 | ~95% | 底部红框 + 品牌授权说明 |
| 拼多多普通店铺 | ~50-80% | **风险高**,看店铺评分 / 销量 / 是否品牌官方认证 |
| 个人代购 / 闲鱼 / 微商 | ~30-70% | **风险极高**,看代购口碑(但难验证) |

**怎么验真**:
- 防伪码:雅诗兰黛 / 兰蔻 / SK-II 都有官方防伪码查询,买后**立刻验**
- 批号查保质期:`https://checkfresh.com` 输入批号查生产日期 + 保质期
- 包装做工:小细节(标签印刷质量 / 瓶身光泽 / 喷头质感)肉眼可辨,但需要对比真品
- 浓稠度 / 气味:用过真品的能感觉到,但不绝对

**判断措辞**(警惕场景):
> "拼多多 ¥180(普通店铺,非百亿补贴)— **真假货风险高**。
> 雅诗兰黛 50ml 国内官旗 ¥906,保税仓 ¥280。¥180 比保税还低 35%,**几乎确定不是真品**;**强烈不建议**。
> 如果非要买,**收货立刻验防伪码 + 批号查生产日期**,有问题 7 天无理由退。"

## 5. 维度 E — 大促形态(美妆不打面价)

**核心**:美妆大牌 618 / 双11 **几乎不直接降面价**(国际品牌的全球价格管理协议禁止公开折扣),促销靠"**加赠量**"。

| 时点 | 雅诗兰黛常见促销形态 |
|---|---|
| 日常 | 50ml ¥906 + 等量 50ml 樱花水 |
| 38 妇女节 / 99 划算节 | 50ml ¥906 + 50ml 樱花水 + 30ml 同款赠品 |
| 618 / 双11 | 50ml ¥906 + 50ml 樱花水 + 50ml 正装小棕瓶赠品(等量买赠等价品,**关键节点**)|
| 直播间(李佳琦)| 30ml ¥660 + 580 元价值赠品(限直播间款) |

**判断"等不等大促"**:
- 美妆**等大促的差异**主要在"赠品量翻倍"而不是"面价降 30%"
- 急用 → 现在买,日常的等量买赠已经实在
- 不急(< 1 月到 618 / 双11)→ 等,赠品量会翻倍,折合克单价更低
- 仓位充裕(屯 1 年量)→ 等大促囤货,这时候买最划算

**与 3C 的核心区别**:
- **3C**:大促降面价 → 等大促 = 直接省钱
- **美妆**:大促加赠品 → 等大促 = 多得不同的赠品 / 同款翻倍

## 6. 综合判断模板(美妆专用)

模板和 3C 不同 —— 美妆判断**不下"该买 / 不买"的硬结论**,而是给"决策框架 + 你来选" 的回答。

**模板 1 — 国内官旗价(行情中)**:
> "雅诗兰黛 50ml 京东自营 ¥906 + 赠 50ml 樱花水。
> - 算克单价:¥18.1/ml(主品)
> - **行情参考**:这是雅诗兰黛国内官旗常态价,不算特别便宜也不算贵 —— 国际大牌国内全年价格波动不大
> - **更便宜的渠道**:保税仓 ~¥280(克单价 ¥5.6/ml,但售后流程长 + 非中国版)、海淘 < ¥400(克单价 ¥8/ml,但邮期 2-4 周)
> - **你的决策点**:
> - 接受 ¥906 + 国行 China-care + 即买即用 → 现在买
> - 接受售后流程长 + 几周邮期,想省 60% → 走保税仓 / 海淘
> - 等 618 → 同价位赠品会翻倍(主品 + 樱花水 + 同款 50ml 正装),克单价更低
> - 没有'最优解',看你哪个需求优先。"

**模板 2 — 拼多多 / 第三方明显低价**:
> "拼多多 ¥180 —— **强烈警惕假货**。
> 雅诗兰黛 50ml 真实渠道下限:保税仓 ¥280,海淘 < ¥400。¥180 比保税还低 35%,**几乎确定不是真品**。
> 如果店铺**不是百亿补贴**(底部无红框)→ 直接放弃。
> 如果是百亿补贴但仍 ¥180 → 罕见,可买但收货立刻验防伪码。"

**模板 3 — 数据不足(知名度低 / 小众品牌)**:
> "[商品] 我能拿到的行情数据有限。可以告诉我:
> - 这是什么类型(精华 / 面霜 / 卸妆 / 防晒)?
> - 你常买的渠道是?
> 然后我帮你看渠道差倍数是不是正常。"

## 7. 不在 覆盖范围

下列**美妆相关品类**,仍走 `non-3c-fallback` 退路:

- **香水**:渠道格局不同(免税店 / 代购 / 国内专柜),克单价 + 渠道差倍数 框架要重写
- **彩妆**(口红 / 粉底 / 眼影):不是"克单价"维度,而是"色号 / 限量 / 联名" 维度,完全不同
- **国货护肤**(珀莱雅 / 薇诺娜 / 自然堂):促销机制跟国际大牌不同(国货爱打面价折扣)
- **医美 / 美容仪**:走 3C 路径(已覆盖)

这些品类未来加规则时会补到 references/judgment-rules-cosmetics-extended.md 或独立文件。

## 8. 与 3C 判断的对照

| 维度 | 3C(judgment-rules-3c.md) | 美妆(本文件) |
|---|---|---|
| 主判断维度 | 折扣率 + 历史曲线 | 克单价 + 渠道差倍数 |
| 大促意义 | 直接降面价 | 加赠品(面价不变) |
| 假优惠形态 | 渠道掉档(港版冒充国行) | 真假货风险(渠道身份不实) |
| 判断结论形状 | "该下手 / 等大促 / 假优惠" | "框架 + 你来选" |
| 数据源 | WebSearch(主)+ 慢慢买(辅) | WebSearch + 行业行情参考表 |
| 历史曲线作用 | 强(看趋势)| 弱(美妆价格年间波动小)|
