# category-detection.md — 三分支品类识别

> ⏱️ **DATA-TIMESTAMP**: 2026-05-29 — 内置规则/价格/政策按此时点;**6 个月内有效**,过期建议 WebSearch 重新验证当前政策。

**作用**:被 `SKILL.md` 的 Step 2(Category Detect)Read。决定走"3C 量化判断"、"护肤美妆框架判断"、还是 `non-3c-fallback` 退路。

**核心**:本版**3 个判断路径**,不是简单的"3C vs 非 3C" 二分。承认能力边界,但能给的尽量给。

---

## 1. 决策树(三分支)

```
输入:商品(品名 / 链接 / 描述)

Q1｜关键词命中 3C 白名单?(见 §2)
 ├── 是 → 进 Q1.5(进一步确认)
 └── 否 → 进 Q2

Q1.5｜不在模糊地带 / 不属于美妆?(见 §5)
 ├── 是 → ✓ **3C/数码 品类**,走 judge / timing / debunk 模式
 └── 否 → 走 §5 模糊地带处理

Q2｜关键词命中**护肤美妆白名单**?(见 §3)
 ├── 是 → ✓ **护肤美妆主品类**,走 cosmetics-judge 模式
 └── 否 → 进 Q3

Q3｜关键词命中**non-3c-fallback 黑名单**?(见 §4)
 ├── 是 → ✓ **退路品类**(服饰/食品/日用/香水/彩妆/国货护肤),走 non-3c-fallback
 └── 否 → 进 Q4(品类不明)

Q4｜从用户语境推断
 ├── 用户提到"国补 / 教育版 / 以旧换新 / 双11 / 618" → 倾向 3C
 ├── 用户提到"克单价 / ml / 渠道 / 保税 / 海淘 / 等量买赠" → 倾向护肤美妆
 ├── 用户提到"配方 / 成分 / 试用装 / 小样" → 倾向美妆或食品 → 看具体
 └── 仍不明 → **直接问用户**:"这是 3C、护肤美妆、还是别的品类?判断框架不一样"
```

## 5. 模糊地带 — 走哪条?

| 商品 | 走哪 | 理由 |
|---|---|---|
| **电动牙刷**(飞利浦/欧乐 B) | **3C** | 算小家电,有国补,京东自营主渠道,有历史曲线 |
| **美容仪**(雅萌/初普/科莱丽) | **3C** | 算小家电/数码,有平台横评和大促规律 |
| **吹风机**(戴森) | **3C** | 小家电,数码渠道 |
| **智能手表**(Apple Watch / 华为) | **3C** | 数码 |
| **运动手环**(小米/华为) | **3C** | 数码 |
| **VR 头显**(Quest / Vision Pro) | **3C** | 数码 |
| **机器人玩具**(乐高机器人 / Anki) | **看情况** | 编程机器人 → 3C;纯玩具 → fallback |
| **电子词典**(网易有道) | **3C** | 数码 |
| **平衡车 / 电动滑板车** | **3C** | 小米/九号有平台规律 |
| **健身设备**(智能体脂秤 / Keep 设备) | **3C 偏弱** | 智能硬件算 3C,但判断规则的"国补"维度可能不适用 |
| **办公椅 / 升降桌** | **fallback** | 家具品类 |
| **音响 / 黑胶机**(发烧友) | **3C 偏弱** | 入门级走 3C,高端发烧级走 fallback |
| **手表(非智能)** | **fallback** | 钟表/奢品品类 |
| **首饰 / 黄金** | **fallback** | 品类完全不同 |
| **国货护肤 / 完美日记**(美妆但非国际大牌) | **fallback** | 未覆盖(国货促销机制不同) |
| **香水**(国际大牌)| **fallback** | 未覆盖(渠道格局不同,免税店 / 代购 / 国内专柜) |

**判定原则**:
- **有国补 + 京东自营是主渠道 + 有版本/型号迭代 + 价格透明** → 倾向 3C
- **国际大牌护肤(精华/面霜)+ 用克单价讨论 + 渠道复杂(专柜/保税/海淘)** → 倾向 cosmetics-judge
- **其他垂直品类 / 未建规则的品类** → fallback
- 仍不确定 → **直接问用户**

## 6. 三种模式怎么走

### 6-1. 3C/数码 — `judge / timing / debunk` 模式

判定为 3C 时 SKILL.md 走的输出形态:**给"该下手 / 等大促 / 假优惠" 硬结论**。

```
[输出]: 一句判断 + 跨平台横评 + 历史一句话 + (可选)假优惠提示 + "想要更多吗"
[判断依据]: judgment-rules-3c.md(折扣率 + 曲线长度 + 国补时机 + 渠道差价 四维)
```

### 6-2. 护肤美妆 — `cosmetics-judge` 模式

判定为美妆主品类时 SKILL.md 走的输出形态:**不下硬结论,给决策框架**。

```
[输出]: 克单价计算 + 渠道差倍数对照表 + 等量买赠折算 + "你的决策点(渠道/时机/赠品用不用)" + "想要更多吗"
[判断依据]: judgment-rules-cosmetics.md(克单价 + 渠道差倍数 + 等量买赠 + 真假货 + 大促形态 五维)
[关键差异]: 给"国内即买即用 / 保税仓便宜但售后长 / 海淘最便宜但邮期长 / 等大促赠品翻倍" 四个选项,让用户按自己优先级选
```

### 6-3. 其他 — `non-3c-fallback` 退路

```
[判断]: "{商品}是 X 品类(服饰/食品/日用 等),没建相应判断框架。"

[能给的]:
- 参考价格区间(从 WebSearch 拿到的几个渠道价,标"参考")
- 这个品类的常见"假优惠"陷阱(给个 1-2 行提示)
- 建议外部工具:慢慢买 App、什么值得买、值值值、海淘攻略站(Extrabux)

[不给的]:
- "该不该现在买"的硬结论
- "等大促能更低"的预测(品类规律不同)
- "假优惠"指控(没有量化阈值)

[结尾]: "如果你拿到具体某家的价 + 想知道是不是好价,可以贴个 ¥X,我帮你查行业行情区间;但'该不该买'的判断,这版我给不了。"
```

## 7. 国货护肤白名单(扩展)

国货护肤判断框架**与国际大牌完全不同**(打面价折扣 vs 加赠品),走 `cosmetics-domestic-judge` 模式,详见 `references/judgment-rules-cosmetics-domestic.md`。

### 国货护肤白名单(命中即走 cosmetics-domestic-judge)

**一线国货**:珀莱雅 / 薇诺娜 / 自然堂 / 韩束 / 百雀羚 / 相宜本草 / 美加净

**新锐国货**:玉泽 / 至本 / HBN / 米蓓尔 / 谷雨 / 林清轩

**边界**:城野医生(日货但运营 + 大促节奏跟国货一致 → cosmetics-domestic-judge);完美日记 / 花西子(国货**彩妆**,维度不同,仍走 fallback)

### 模式: `cosmetics-domestic-judge`

判定为国货护肤主品类 → 给"**该买 / 等大促 / 抢直播**" 硬结论(跟 3C 接近,**不像国际大牌"决策框架"**)。

```text
[输出]: 一句判断 + 折扣率分析 + 历史大促底 + 距下次大促时间 + "想要更多吗"
[依据]: judgment-rules-cosmetics-domestic.md
[关键差异]: 主维度是折扣率(不是克单价),促销看面价(不是赠品翻倍)
```
