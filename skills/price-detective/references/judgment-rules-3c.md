# judgment-rules-3c.md — 3C 品类判断规则

> ⏱️ **DATA-TIMESTAMP**: 2026-05-29 — 内置规则/价格/政策按此时点;**6 个月内有效**,过期建议 WebSearch 重新验证当前政策。

**作用**:被 `SKILL.md` 的 Step 4(Judge)Read。把抓到的真实数据翻成"该买 / 等 / 假优惠" 的判断。

**核心**:4 个维度 —— 折扣率 / 曲线长度 / 国补时机 / 渠道差价。每个维度有**具体数字阈值**,不是模糊形容词。

---

## 0. **优先维度 — 产品年龄 / 生命周期**

**核心**:**电子产品有生命周期**。即使折扣率好、价格符合历史规律,**老款 + 接近换代** = 不推荐买。**先看年龄,再看价格**。

### 0-1. 年龄分档

| 距发布时长 | 状态 | 判断态度 |
|---|---|---|
| **< 6 月** | 新品 | 折扣有限正常;**生命周期价值最高**,买了能用 3-5 年 |
| **6 - 18 月** | 中代 | 按 §1 §2 常规规则判断 |
| **18 - 24 月** | **准末代** | **警惕区** — 下一代可能即将发,**残值快速折损** |
| **> 24 月 + 新一代已发** | **末代** | 清库存价才考虑;**平时不推荐**,即使便宜 |
| **> 30 月 + 跨过两代** | **超老款** | **强烈不推荐**,即使白菜价也不值 |

### 0-2. **老款"涨价"是需要权衡的信号(违反直觉)**

老款产品的"涨价" **跟新品涨价含义不同**:

- **新品涨价** = 需求 / 内存 / 品牌策略 → 涨完平稳,正常
- **老款涨价** = 多数是**库存清完 + 黄牛挺价 + 经销商利润紧缩** → 涨完几个月内新一代发布 → 通常断崖式跌或下架

**遇到"老款 + 涨价 + 下一代信号"** → **不下"该不该买" 硬结论**,而是给用户**信号 + 权衡框架**:

> **"现在不是最佳时机,有几个信号你需要权衡:
> ① 老款 X 个月(准末代区);
> ② 当前涨价 ¥Y(典型清仓涨价信号,**但不绝对**);
> ③ 下一代 [型号] 预计 [时间] 发布(信号来源:[新闻链接],**置信度: 中/高**,以官方公告为准)。
>
> **以下情况你可以现在就买**:急用 / 不在乎转手保值 / 等不了 [N] 周到新一代落地。
> **以下情况建议等几周**:不急 / 在乎残值 / 想看新一代价格再决定。
>
> 决策权在你,我给信号不给断言。"**

**为什么不下硬结论**:下一代发布时间多数来自分析师推测(古尔曼 / 9to5Mac / IT之家 报道),**不是官方公告**。把推测当事实给"绝对不要买" = 违反 SKILL.md "不替用户下单" 边界。

### 0-3. 实例:Mac mini M4(2024-10 发布 → 2026-05 是 19 个月)

**当前情况**(2026-05 真实数据,WebSearch IT之家 / 新浪科技):
- 苹果 5 月 1 日下架 256G 入门版,起售价 ¥4499 → ¥5999(**+¥1500**)
- 涨价原因:AI 服务器挤占消费级内存芯片产能,M4 库存紧张
- 落入 **"准末代"区间**(18-24 月)

**新一代信号**(WebSearch IT之家 / 古尔曼报道):
- **M5 Mac mini 大概率 2026-06 WWDC 发布**(< 1 月!)
- 性能提升 15% + GPU 大升级 + 神经引擎 40T ops/秒
- 沿用 M4 设计,**纯内部升级**

**正确判断**:

> **现在不是最佳时机**(2026-05-29 抓),有 3 个信号你需要权衡:
>
> 1. **老款 19 个月** — 落入准末代区(18-24 月,残值快速折损区间)
> 2. **价格涨 ¥1500**(¥4499 → ¥5999)— 多数情况下是清仓涨价信号,**但不绝对**(也可能是 AI 内存需求驱动)
> 3. **M5 推测临近** — 多个报道指向 2026-06 WWDC 发布,**但这是分析师推测,不是官方公告** —— 置信度: 中
>
> **以下情况你可以现在就买**:
> - 急用(等 4-6 周影响工作 / 生活)
> - 不在乎转手保值
> - 已知 M5 不会大跨度升级(沿用 M4 设计,纯内部升级,你不在乎视觉"新")
>
> **以下情况建议等几周看看**:
> - 不急(可以等到 WWDC 后再决定)
> - 在乎残值(末代购入 1 个月内贬值最快)
> - 想看 M5 价格落地后再权衡(M5 性能 +15%,起售价可能跟 M4 涨后差不多)
>
> **决策权在你,我给信号不给断言**。新闻原文请自己读核验(见末尾链接)。

### 0-4. 怎么抓发布时间 + 下一代状态

**必查信号**(Step 3 抓数据时同时抓):

- WebSearch `"{品牌} {型号} 发布时间"` — 拿上市日期
- WebSearch `"{品牌} {下一代型号} 发布 2026 2027"` — 拿下一代时间表
- 看 IT之家 / 新浪科技 / 古尔曼报道 / 苹果官网 公告

**判断"下一代是否临近"**:

| 距下一代发布 | 判断 |
|---|---|
| < 1 月 | **强烈不推荐买当前代** |
| 1-3 月 | **不推荐买**,等清仓底 |
| 3-6 月 | **看清仓底 vs 新代价**,有真清仓底再入 |
| 6-12 月 | 按常规规则,可买 |
| > 12 月 / 没有时间表 | 按 §1 §2 常规判断 |

### 0-5. **特别注意:Mac / iPhone 等 Apple 大件**

Apple 产品**生命周期规律**:
- 每代约 12-18 月发新
- 老代发布 18-24 月后立刻"清仓 + 涨价"双轨(库存挺价,新品蓄势)
- 涨价≠正常需求,**是清库存策略**
- **永远关注 WWDC(6 月)和 9 月 Apple 发布会**两个节点

**iPhone 系列**:9 月发新,跑 18 月生命周期后清仓
**Mac 系列**:WWDC(6 月)或秋季发新,12-18 月迭代
**iPad / Apple Watch**:不定期,但通常 12-24 月

### 0-6. 跟其他维度的关系

| 维度 | 在年龄判断后的角色 |
|---|---|
| §1 折扣率 | **年龄不利 → 折扣率即使 70% 也不算好**;**年龄好 → 折扣率 90% 也可买** |
| §2 曲线长度 | 跟年龄高度相关,**合并看** |
| §3 国补 vs 大促 | 老款国补可能退坡(政策不覆盖停产品类) |
| §4 渠道差价 | 老款渠道差异更大(库存紧张 → 黄牛挺价) |
| §7-1 末代清库存 | **本规则是 §7-1 的补充** — 末代不只有清库存好价,也有"末代涨价" 陷阱 |

### 0-7. **措辞匹配置信度**

**核心**:措辞强度**必须**匹配信息置信度。**预测性信号**用温和措辞 + 让用户权衡;**确定性事实**才能用强措辞。

| 信息类型 | 例子 | 该用的措辞 | **不该用的措辞** |
|---|---|---|---|
| **官方公告事实** | 苹果官网"M4 起售价 ¥4499 → ¥5999"(已发布) | "确认涨价 ¥1500" "已经下架" | (强措辞 OK) |
| **历史价格数据** | 慢慢买 / WebSearch 抓到的真实成交价 | "近 1 年大促底 ¥348" "2025-11.11 探到 ¥299 限量" | (强措辞 OK,但限量要标注) |
| **分析师 / 媒体推测** | "M5 大概率 2026-06 WWDC"(古尔曼推测) | "**多个报道指向 X**" / "**信号:Y**" / "**置信度:中**" | ❌ "**M5 一定** 6 月发" / "**绝对** 不要买" |
| **趋势 / 经验规律** | "老款涨价通常是清仓信号" | "**多数情况下**是 X" / "**通常**" / "**但不绝对**" | ❌ "**一定**是 X" / "**铁律**" |
| **未来价格预测** | "M5 起售价可能 ¥6499 区间" | "**可能** ¥X-Y" / "**预测区间**" / "**不保证**" | ❌ "**保证**" / "**一定**" / "明天 ¥X" |

**输出强度对照表**:

| 信号强度 | 该用的判断措辞 |
|---|---|
| 全是确定事实 + 多源一致 | "**建议下手** / **建议等大促**"(可以给硬建议) |
| 大部分是事实 + 少量推测 | "**看起来现在/等** 更合适,因为..."(温和) |
| 一半事实 + 一半推测 | "**现在不是最佳时机** / **有几个信号你需要权衡**"(给信号 + 让用户选) |
| 大部分是推测 / 数据不足 | "**不下硬判断** / 我给信号,你权衡"(明确弱化) |

### 0-8. **置信度披露**

参考 promo-predictor 的"置信度高/中/低" 标注 — **price-detective 也必须标置信度**,且**判断中涉及推测的部分必须单独标**。

**披露格式**:

> "判断:{结论}。
> 置信度:**{高/中/低}**(基于:{真实数据点 N 个} + {推测信号 M 个})。
> {如有推测信号}:推测来源:{新闻链接},以官方公告为准。"

**实例**(Mac mini M4):

> "判断:现在不是最佳时机。
> 置信度:**中**(基于:确定事实 2 个 — 涨价 ¥1500、老款 19 月;推测信号 1 个 — M5 WWDC 推测)。
> M5 时间推测来源:古尔曼报道 / IT之家 2025-11,以苹果官方公告为准。"

## 1. 维度 A — 折扣率(当前价 vs 官方原价)

**计算**:`含国补到手价 ÷ 官方原价(MSRP)`

| 折扣率 | 判断 | 措辞 |
|---|---|---|
| ≥ 95%(几乎不打折) | 不是好价 | "现在基本是原价,可以等大促或国补政策" |
| 90-95% | 一般 | "略有优惠,如果不急可以等" |
| 85-90%(9 折以下) | **算好价** | "对 Apple/3C 大件已经算实在,可考虑下手" |
| 80-85% | 真好价 | "明显低于平时,建议下手" |
| < 80% | 历史性好价 | "罕见低价,如非品类清库 / 限量,值得抓" |

**注意事项**:
- **官方原价**指品牌官网定价(Apple `apple.com.cn` / 华为/小米 官方),不是平台标的"划线价"(划线价水分大)
- **国补**要算进到手价 —— Apple/3C 大件 2024-2026 国补 15-20%,折扣率不算国补会被严重高估
- 教育版 / 学生价 / Plus 价 → **不算在通用折扣率里**(用户身份门槛),单独标注

**实例**(e2e 001 — Apple M5 Pro 14"):
- 官方原价 ¥17999,国补 + Plus 后 ¥16409
- 折扣率 = 16409 / 17999 = **91.2%** ← 9.1 折,**算好价**

**实例**(e2e 003 — 罗技 MX Master 3S):
- 上市原价 ¥899,当前活动 ¥469(新人 30 后)
- 折扣率 = 469 / 899 = **52.2%** ← 5.2 折,**真好价**(但还有维度 B 要看)

## 2. 维度 B — 曲线长度敏感(老品 vs 新品)

**核心洞察**:同样是"历史新低",**新品和老品含金量天差地别**。

### B-1. 新品(上市 < 3 个月)

- 慢慢买"历史新低" 标签**含金量打折** —— 因为窗口太短,可能只是上市后第一次促销
- **退而求其次**:用"含国补 vs 官网原价" 折扣率(维度 A)代替历史比较
- **措辞**:"这是 2 个月内的最低,但新品曲线短,'新低'参考价值有限"
- **不要**说"历史最低,闭眼入"

**实例**(e2e 001 — M5 Pro 14"):
- 2026-03 发布,2026-05 测试 → 仅 2 个月曲线
- 慢慢买给"历史新低 + 含国补"
- 处理:**标注**"新品曲线短,新低含金量有限,但 9.1 折对 Apple 大件实在"

### B-2. 老品(上市 > 2 年)

- 历史曲线**很硬** —— 经过多个 618/双11 大促周期,价格上下限稳定
- **主判断维度**:`当前价 ÷ 近 1 年大促底`
- 阈值:

| 当前价 vs 近 1 年大促底 | 判断 |
|---|---|
| < 105%(差价 < 5%) | **价格到位**,可以下手 |
| 105-115%(差价 5-15%) | 可以等 — 多数大促有 5-15% 降空间 |
| > 115%(差价 > 15%) | **强烈建议等大促** — 这是平时价,不要现在买 |

**实例**(e2e 003 — 罗技 MX Master 3S):
- 当前价 ¥469
- 近 1 年大促底:2025-11.11 ¥348,2025-10 国补 ¥366
- 当前 / 近一年底 = 469 / 348 = **134.8%** ← 高出 35%
- 判断:**强烈建议等大促**,距 618 不到 1 个月,大概率破 ¥350

### B-3. 中年品(3 月 - 2 年)

- 历史曲线**够看,但不够硬**
- 主判断:看是否经历过至少 1 个大促节(618 / 双11 / 国庆 / 38),**有过的话**用近 1 年大促底
- **没有**完整大促数据 → 用"折扣率 + 慢慢买标签" 组合,慎下"等大促"建议

## 3. 维度 C — 国补 vs 大促时机

**这是 2024-2026 中国市场最重要的判断点**:国补与大促的关系,**违反过去 10 年的"等大促"经验**。

### C-1. 国补在生效期(常态:2024 至今,逐年降幅)

- 多数 3C 大件、家电享 15-20% 国补
- 京东自营、天猫官旗 直接抵扣
- **关键**:**国补 + 平台券 + Plus** 叠加后的到手价,**通常低于 618/双11 的非国补降幅**
- 大促时**国补可能退坡**(品类调整、补贴名额限制)

**经验法则**:
- **国补在 + Plus 在 → 别等大促**,大促可能国补减少反而更贵(Apple/家电 已有先例)
- **国补在但 Plus 不在** → 临近大促可等(平台券会加力度)
- **国补不在** → 看大促临近度(< 1 月:等;1-3 月:看品类历史规律)

### C-2. 国补判定线索

抓 WebSearch 时看这些信号判断"国补在不在":
- 报道里有"含国补"、"国补价"、"15% 国家补贴"、"以旧换新国补" → 国补在
- "原价 X,国补后 Y"、"叠加云闪付 15%" → 国补在
- 只有"立减 / 满减 / 券" → 国补可能不适用(品类不在补贴范围 或 政策窗口外)

### C-3. 大促临近度

- **< 2 周临近** + 国补在 → 看历史大促对该品类是否有"超国补"力度;没有 → 现在买
- **< 1 月临近**(如本测试 2026-05-28 离 618 ≈ 3 周) → 多数品类**值得等**,历史大促底是硬参考
- **> 1 月** → 别为大促等,机会成本高;有合适价就下手

**实例**(e2e 001 vs e2e 003):
- **M5 Pro**:国补在,Apple 历来 618 自降幅度小于国补,**不等大促**
- **罗技 MX Master 3S**:国补未显示在 2026-05 报道,618 临近,历史 618 ¥299 / 11.11 ¥348,**等大促**

## 4. 维度 D — 渠道差价(戳穿"假优惠"的核心)

**核心**:Apple/3C 的"假优惠"**多数不是划线水分**,而是**渠道掉档**(港版/教育版/海外版冒充国行)。

### D-0. **判断顺序**

**先查"合法差价豁免清单"(D-1.5),再查差价百分比阈值(D-1)。** 跳过这一步会把"国行 vs 海外版" 这种已知合法差价误报为"假优惠"(e2e 005 T3 暴露)。

### D-1. 京东自营 vs 第三方差价阈值

| 第三方店价 vs 京东自营 | 判断 |
|---|---|
| 同价或略高 | 正常,选信任度高的(京东自营售后更稳) |
| 比京东自营**便宜 < 5%** | 正常,可能是店铺活动 / 凑单 |
| 比京东自营**便宜 5-8%** | 留意,大概率是店铺会员 / 早抢优惠 |
| 比京东自营**便宜 8-15%** | ⚠️ **警惕**(若未命中 D-1.5 豁免):港版 / 教育版 / 海外版 / 激活机 / 翻新 |
| 比京东自营**便宜 > 15%** | 几乎确定有问题(若未命中 D-1.5 豁免):水货 / 翻新 / 假货 / 钓鱼链接 |

### D-1.5. **合法差价豁免清单**

下列情况差价超 15% **也是合法的**,不能套 D-1 警惕规则。判断时**先看是否落在豁免**,再看百分比:

| 豁免类型 | 典型差价 | 谁是合法差价 | 判断措辞 |
|---|---|---|---|
| **国行 vs 海外版** | 15-30% | Sony / Bose / 任天堂 / GoPro / 大疆海外版 | "差价 X% 是已知合法差价(海外版无国行售后 + 中文 App 服务)。两个都正品,看你接不接受售后流程长 + 英文 UI" |
| **国行 vs 教育版** | 8-15% | Apple / Microsoft / Adobe 教育版 | "教育版需学生/教师身份,**限购**,不能官方维修;省下 8-15% 看你符不符合资质" |
| **京东自营 vs 拼多多百亿补贴** | 5-15% | 平台让利,品牌授权 | "百亿补贴(底部红框/Logo)是平台让利,正品,可买。**普通拼多多店铺**差价 > 5% 仍然警惕" |
| **国行 vs 港行 / 日行** | 10-25% | iPhone / iPad / Switch / 索尼电视 等 | "税率差异决定的合法差价。港行/日行无国行联保,只能寄回购买地修;充电规格、App Store 区域可能不同" |
| **京东自营 vs 苏宁 / 国美**(渠道补贴) | 5-10% | 平台之间的同期补贴竞争 | "正常渠道竞争,可选信任高的" |
| **京东自营 vs 抖音直播间**(主播让利) | 5-15% | 头部主播专属补贴 | "主播让利,正品概率高,但**售后走主播渠道**可能流程不同" |

### D-1.6. 判断流程图

```
看到差价 X% → 检查 D-1.5 豁免:
├── 命中豁免 → 按豁免类型给"已知合法差价"判断 + 说清两边各适合谁
└── 未命中豁免 → 按 D-1 百分比阈值警惕

例(T3):索尼 WH-1000XM5 国行 ¥2488 vs 海外版 ¥1888,差 24%
 → 命中 D-1.5 "国行 vs 海外版" 豁免
 → 不是 D-1 的"> 15% 几乎假货"
 → 输出:已知合法差价,给"国行 vs 海外版" 适用人群分流
```

### D-2. 各"渠道掉档"陷阱识别

| 陷阱 | 表现 | 怎么辨 |
|---|---|---|
| **港版冒充国行** | 价低 8-12%,标"全新国行" | 看说明书 / 包装语言、查序列号、不能享 China-care |
| **教育版限购流出** | 价低 10-15% | 国行教育版需学生身份 / 教师身份,流出代购**不享官方维修** |
| **海外版**(美版/日版) | 价低 10-20% | 充电头插脚不同;App 区域可能受限;无国行保修 |
| **激活机 / 官换机** | 价低 5-10% | 序列号已激活;保修从激活日起算,不是从购买日 |
| **翻新机** | 价低 15-30%,标"全新" | 外观新但内部翻新;可通过序列号在 Apple/官网验 |
| **钓鱼链接** | 价低 > 30%,催"快下单" | 网址非官方 / 非主流平台;**不要相信** |

### D-3. 拼多多特殊情况

- 拼多多**百亿补贴**频道:正品价通常**确实低于** 京东自营 5-10%,且是国行
- 拼多多**非百亿补贴店铺**:差价 > 10% 一律**警惕**
- 用户问"拼多多 X 元" → 先问"是不是百亿补贴",再判断

## 5. 综合判断模板(最终输出)

把维度 A + B + C + D 综合后,标准的一句判断长这样:

**模板 1 — 该下手**:
> "当前 ¥X(京东自营,2026-05-28)= [折扣率] / [vs 近一年大促底比值],**算好价**。国补在生效期,等大促风险:[国补退坡可能 / 等不到更低]。**建议下手**。"

**模板 2 — 等大促**:
> "当前 ¥X = [比近一年大促底高 N%],距 [618/双11] [N 周],历史大促底 ¥Y([日期])。**建议等**,大概率能省 [N%]。"

**模板 3 — 假优惠**:
> "这家 ¥X,比京东自营低 [N%] —— 落在 [警惕区间]。**强烈怀疑** [港版/教育版/翻新机]。建议核 [店铺资质 / 序列号 / 包装]。"

**模板 4 — 新品稀释**:
> "新品(上市 [N] 个月),'历史新低'仅 [N] 月窗口,**含金量打折**。但折扣率 [A%] 对 [品牌/品类] 大件已经实在,**可考虑**。"

**模板 5 — 数据不足**:
> "[商品] 当前 ¥X,近期独立报道少。我能拿到:[简述]。**不下硬判断** —— 建议你去慢慢买 App 查历史曲线截图,我帮你解读。"

## 6. 边界场景

- **品类切换**:用户从"罗技鼠标"切到"罗技耳机" → 重新走 Step 1-4,**不要复用上一个商品的判断**
- **配置不同**:同款不同 SKU(M5 Pro 24G vs 48G)→ **必须分别判断**,不能用 24G 的折扣率推 48G
- **多个商品**:用户贴两个不同商品 → 分别走一遍,最后给"两个里更推荐 X" 的对比
- **限时优惠**:报道里"限量 200 台 / 20:00 抢" → 标"这是限时活动,以下单时为准"

## 7. 特殊价格情况

下面 4 种价格不能套常规折扣率/曲线判断,要专门识别 + 单独处理。

### 7-1. 末代清库存价(品类换代时)

**特征**:
- 新一代产品**刚发布**或**即将发布**(WebSearch 能搜到"X 系列发布会"、"X 下一代渲染图")
- 旧款价格**断崖式下降**(跌 30%+),且持续 1-2 个月
- 商品描述里可能出现"经典款" / "末代" / "停产前清仓"

**判断**:
- 价格**确实是好价**(可能跌破历史曲线最低)
- 但要**告诉用户**:"这是末代清库存价,买了之后**不要期望保值**,新一代发布后这款会停售 / 不再有官方维护更新"
- **谁该买**:急用 / 不在乎最新一代 / 性价比导向的用户
- **谁不该买**:在乎"未来 3 年还想保持新款" / 系统更新及时性 / 转手保值

**实例**:
- 2023-09 iPhone 14 Pro 在 iPhone 15 发布前 1 个月跌至 ¥5999(原价 ¥7999),是历史新低 —— 但 1 个月后就停售
- M5 Pro 发布时,M4 Pro 同配置降价 30% 但停产倒计时
- 处理:**两段输出** —— "这是好价 ✓,但接受'末代'代价 ✓ → 决策权给用户"

### 7-2. 限量抢购价(不能作为常规历史价)

**特征**:
- 报道明确写"**限量 X 台**" / "**20:00 准点**" / "**前 200 名**" / "首发限量"
- 价格远低于其他时点(往往低 30-50%)
- 抢到概率低,多数用户**抢不到**

**判断**:
- **不能**把这个价当成"历史最低"用作"等大促就有"的参考
- 应该**单独标注**:"这是限量价,不是常规价。绝大多数用户在限量时段后看到的是平时价 / 半价 / 国补价(列出来)"
- 用 "**常规历史最低**" 而不是 "**历史最低**" 作判断锚点

**实例**(e2e 003 罗技 MX Master 3S):
- 2024-06 ¥299 是"限量 200 台 20:00 抢"
- 2025-11.11 ¥348 是常规大促价(全天可买)
- 用 ¥348 当判断锚点,不是 ¥299
- 输出:"历史最低 ¥299 是限量秒杀,绝大多数人抢不到;**常规大促底 ¥348**,这是你能合理期待的"

### 7-3. 新品上市头 30 天溢价

**特征**:
- 产品上市 < 30 天
- 价格 = 官方原价,**没有任何促销**
- 慢慢买 / WebSearch 找不到"国补 / 满减 / Plus 优惠" 报道

**判断**:
- **几乎不可能算"好价"** —— 厂商上市头 30 天靠饥饿营销,价格刚性
- 等 **60 天后**:多数 3C 会启动第一波促销(平台券 / 国补 / Plus)
- 等 **首个大促节**(上市后第一个 618 / 双11):价格才真正进入"可议价" 区间

**判断措辞**:
- "这款刚上市 X 天,价格还在'原价坚挺期'。**急用就买**,不急 → 等 30-60 天首次促销,大概率能省 5-10%;**等首个大促节**(下次 618 / 双11)能省 10-15%"

### 7-4. 周年庆 / 黑五 / 国庆 / 38 妇女节(非顶级大促节)

**特征**:
- 不是 618 / 双11,但有促销活动
- 力度通常**小于** 618 / 双11

**判断**:
- 这种"中等大促"对**老品 / 持续在售品** 有意义(平时和大促的差价 5-10%)
- 对**新品** 通常没影响(厂商不参与)
- 距 618 / 双11 < 2 个月 → 建议等顶级大促;> 2 个月 → 中等大促有合适价就下手

**优先级表**(同款 3C 在不同大促的预期降幅):
- 双 11(11.11)≈ 618(6.18):**最大降幅**(10-20%)
- 国庆(10.1)/ 黑五(11 月底)/ 周年庆(各平台不同):**中等降幅**(5-10%)
- 38 妇女节 / 99 划算节 / 88 会员节:**小降幅**(3-7%)

## 8. 数据冲突处理(两个源对不上)

WebSearch 拿到的价跟慢慢买不一样、或者两次 WebSearch 拿到的价不一样 —— 这种情况实际很常见,不能取平均、不能挑一个就背书。

**标准处理**:
1. **诚实并列展示** —— 把两个源 + 各自时间 + 各自数字 都列给用户
2. **猜可能原因**(滞后 / 不同 SKU / 不同活动)
3. **建议用户去下单页核实**(最权威的是用户下单时实际看到的价)
4. **不要**取平均、不要选一个就背书、不要假装没冲突

详见 `examples/demo_conversation.md` 的"边界 3 — 数据冲突"。
