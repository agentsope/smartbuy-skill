# judgment-rules-cosmetics-domestic.md — 国货护肤判断规则

> ⏱️ **DATA-TIMESTAMP**: 2026-05-29 — 内置规则/价格/政策按此时点;**6 个月内有效**,过期建议 WebSearch 重新验证当前政策。

**作用**:被 `SKILL.md` 的 Step 4(Judge)Read。**国货护肤的判断框架与国际大牌完全不同**,本规则单独处理。

**核心**:国货护肤跟国际大牌护肤(雅诗兰黛/SK-II/兰蔻/修丽可)有 3 个根本差异:

1. **打面价折扣**(不靠"加赠品" 套路)— 大促直接降价,看折扣率
2. **大促降幅深**(618 / 双 11 可降 30-50%,有时直播间更深)
3. **真假货风险低**(产能在国内,假货成本不划算)

→ 所以国货可以**给硬判断**(该买 / 等大促 / 直播抢),跟 3C 接近,**不需要走"决策框架"** 模式。

## 2. 判断维度

### 维度 A — 折扣率(主维度)

跟国际大牌的"克单价"不同,**国货直接看折扣率**(国货价格本身就低,克单价对比无意义):

| 折扣率(当前价 ÷ 官方原价)| 判断 | 措辞 |
|---|---|---|
| ≥ 90%(几乎不打折) | 不是好价 | "现在基本是日常价,可以等大促" |
| 80-90% | 一般 | "略有优惠,平时也常这价" |
| 60-80% | **算好价** | "比平时实在,可考虑下手" |
| 50-60% | 真好价 | "明显低于平时,建议下手" |
| < 50% | **历史性好价** | "罕见低价,大促级别,可入" |

**重要**:国货大促降幅深,**< 60% 折扣才算"真好价"**(国际大牌 < 90% 就算好,标准不同)。

### 维度 B — 大促节点(强相关)

| 节点 | 力度 | 典型降幅 |
|---|---|---|
| **618 / 双 11** | S 级 | 30-50% |
| **38 妇女节** | A 级 | 20-30% |
| **99 划算节 / 818 会员节** | B 级 | 15-25% |
| **直播间专享**(李佳琦 / 烈儿宝贝 / 蜜蜂惊喜社) | 不定期 | 30-50%(偶尔更深) |
| **品牌日 / 上新预售** | 中等 | 凑单券 + 赠品 |
| 平时 | 低 | < 10%(看日常打折活动) |

**关键洞察**:**国货真正的大促 = 直播间**,不一定是 618 / 双 11。例如珀莱雅双抗精华日常 ¥249,大促 ¥139,直播间偶有 ¥99-119。

### 维度 C — 渠道真假货风险(低)

国货真假货风险**低于国际大牌**(产能在国内,假货成本不划算)。但仍要识别:

| 渠道 | 真品概率 | 注意 |
|---|---|---|
| 品牌天猫官旗 / 京东自营 | ~100% | 蓝 V 标 |
| 抖音品牌官旗 + 蓝 V | ~98% | 看店铺资质 |
| 拼多多百亿补贴 + 品牌 | ~95% | 底部红框 |
| 抖音 / 拼多多 普通店铺 | 85-95% | 看销量评分 |
| 海外版 / 灰色渠道(国货出海回流)| **批号 / 包装不同** | 不一定假,但售后无门 |

**边界 — 海外版国货**:近年国货品牌(珀莱雅 / 玉泽 等)开始出海,海外版价格通常比国内低 10-30%,**不算假货**,但:
- 批号不同(查官方防伪可能不识别)
- 售后没有国内三包(出问题没人理)
- 包装可能英文 / 多语言

### 维度 D — 直播间专享价识别

国货大促重头在**直播间**。看到直播间价格时:

- **比电商日常低 30%+** → 大概率直播间专享价,**抢到就是赚到**
- **限时 / 限量** → 跟 3C 限量秒杀不同,国货直播间限量通常 1-2 小时,而不是 200 台秒杀
- **赠品翻倍**(直播间送旅行装 / 小样)→ 算总价值
- **预售机制**:大促前预售付定金,大促当天付尾款 + 赠品 → 比当天直接买便宜 5-10%

## 3. 判断模板

### 模板 1 — 该下手(折扣率 < 60%)

> "{商品} 当前 ¥X(京东自营,2026-05-29 抓)。折扣率 {Y}% × 官方原价 ¥{Z} → **真好价**,可下手。
>
> 历史:近 1 年大促底 ¥{底}(618 / 双11),你现在的价已经达到大促级别。
>
> **以你下单页为准**。"

### 模板 2 — 等大促(折扣率 70-90%)

> "{商品} 当前 ¥X。这是日常价,折扣率 {Y}% 不算实在。
>
> 近 1 年大促底 ¥{底}(降 30-40%),建议等下次大促:
> - 618(距今 X 周)
> - 双 11(距今 Y 个月)
> - **直播间**(随时关注李佳琦 / 烈儿,可能比电商大促还深)
>
> **不急 → 等**;急用 → 现在买不亏(国货起价就不贵)。"

### 模板 3 — 直播间专享识别

> "你说的 ¥{X} 是**直播间专享价**?如果是,这是**抢到就是赚到** —— 比电商日常低 {Z}%,大促级别。
>
> 注意:
> - 直播间通常**限时 1-2 小时**,过点回到日常价
> - 直播间赠品多(旅行装 / 大瓶面膜),实际总价值更高
> - 直播间售后走主播渠道,流程跟自营不同
>
> 现在抢得到就抢,不亏。"

### 模板 4 — 海外版警示

> "{商品} ¥{X} 比国内官旗低 {Z}% —— 大概率是**海外版国货**(出海回流):
> - **不一定假**(国货品牌真的有出海)
> - 但**售后无门**(国内三包不认海外批号)
> - 包装可能英文 / 多语言
>
> 你愿意接受没售后 → 可买;在乎售后 → 走国内官旗。"

## 4. 与国际大牌护肤的对照(关键差异)

| 维度 | 国货护肤(本文件)| 国际大牌(`judgment-rules-cosmetics.md`)|
|---|---|---|
| **主判断维度** | **折扣率** | **克单价** |
| **大促形态** | 打面价(降 30-50%)| 加赠品(面价不变,赠品翻倍)|
| **算什么** | 看现价 vs 历史大促底 | 算克单价 + 渠道差倍数 + 赠品折算 |
| **渠道差倍数** | 国内 1.0× / 海外版 0.7-0.9×(有差但不大) | 国内 1.0× / 保税仓 0.3-0.4× / 海淘 0.4-0.6×(差几倍)|
| **判断形态** | **给硬结论**(该买 / 等大促 / 抢直播)| 给决策框架(国内即买 / 等大促 / 保税仓 / 海淘)|
| **真假货风险** | 低(产能国内,假货不划算)| 中-高(渠道掉档严重)|
| **直播间** | **强相关**(国货大促重头)| 弱(国际大牌很少做直播)|
| **大促节点** | 618 / 双11 / 38 / 直播间 | 618 / 双11(都靠加赠品)|

**判断流程图**:

```
用户给护肤品 → 品牌识别
  ├── 国际大牌(雅诗兰黛/兰蔻/SK-II...) → cosmetics-judge (决策框架,克单价)
  ├── 国货大牌(珀莱雅/薇诺娜/自然堂...) → 本文件(硬判断,折扣率)
  ├── 国货新锐(玉泽/至本/HBN...) → 本文件
  ├── 香水 / 彩妆 → non-3c-fallback(暂不覆盖)
  └── 没听说过的小众 → 用户多提供信息或 fallback
```

## 5. 不在覆盖范围

- **香水 / 古龙水**:渠道格局不同(免税店 / 代购),走 fallback
- **彩妆**(口红 / 粉底 / 眼影):看色号 / 限量 / 联名,完全不同维度,走 fallback
- **医美 / 美容仪**:走 3C 路径(已覆盖)
- **保健品 / 口服美容**:不在 0.x 覆盖
- **海淘小众国货** / **跨境购国货**:渠道差倍数尚未建模,提示用户去**慢慢买 + 什么值得买** 自查

## 6. 与 3C 判断的相似点

为什么国货护肤跟 3C 判断像?

| 维度 | 国货护肤 | 3C(`judgment-rules-3c.md`)|
|---|---|---|
| 主维度 | 折扣率 | 折扣率 + 历史曲线 |
| 大促意义 | 直接降面价 | 直接降面价 |
| 判断形态 | 硬结论 | 硬结论 |
| 渠道差价警惕 | 海外版回流 | 港版 / 海外版冒充国行 |

**结论**:国货护肤的判断逻辑**更接近 3C**,不像国际大牌护肤需要"决策框架"。
