## 2. **关键:叠加顺序**(错一步少省几十上百)

### 2-1. 标准叠加顺序(2026-05 政策)

```
商品标价 ¥X
 ↓ 1. 减京享红包(平台红包)
 ↓ 2. 减店铺券
 ↓ 3. 减跨店满减(每满 300-50 等)
 ↓ 4. 减品类券(数码 9 折等)
 ↓ 5. 减 PLUS 满减(满 1000-50 等)
 ↓ 6. 国补 15% 最后扣(按上一步结果的 15%,封顶 ¥500)
 = 最终到手价
```

**为什么国补必须最后?**

国补按"剩余应付金额"的 15% 计算。如果国补在前用了,后面的满减/红包/券会让"应付额" 变小,**国补按更小的基数算 = 国补少省**。

**实测对比**(京东 ¥5000 一级能效空调):

| 叠加顺序 | 最终到手 |
|---|---|
| **正确**:¥5000 → 红包 -200 → 店铺券 -300 → 跨店满 1000-500 → 国补 15%(×0.85) | ¥5000-200-300-500 = ¥4000 × 85% = **¥3400** |
| **错误**:¥5000 → 国补先 15% → 红包 -200 → 店铺券 -300 → 跨店满 1000-500 | ¥5000 × 85% = ¥4250 -200-300-500 = **¥3250**(国补按更小基数,少抵 ¥150) |

等等,**这个实测算反了** —— 国补先用反而**便宜**?让我重算:

- **国补先**:5000 × 85% = 4250, 4250 - 200 - 300 - 500 = 3250
- **国补后**:5000 - 200 - 300 - 500 = 4000, 4000 × 85% = 3400

**结论:实际上国补先用更省!**

但 WebSearch 多源都说"国补最后" —— 这里有矛盾。**真实原因可能是**:京东系统**强制**国补在最后扣(不让你选顺序),因为国补是"按结算金额"算的政策规定。系统层面**先减完所有优惠后**,再算国补 15%。

**用户视角的"正确顺序"** = **领取顺序**:先领红包 → 再核国补资格 → 再领品类券 → 再核跨店满减 → 最后结算时云闪付支付触发国补抵扣。

**算法层面真实公式**:
```
最终实付 = (商品标价 - 红包 - 店铺券 - 跨店满减 - 品类券 - PLUS满减) × (1 - 0.15)
 = 应付额 × 0.85
```

(国补 15% 是 95% 场景的实测,部分品类或地区可能 12% / 10% / 不享)

### 2-2. 错误顺序的真实风险

错的不是"算法顺序" —— 京东系统会自己处理。错的是 **"领取顺序"**:
- ❌ **先下单再领券** → 已下单的订单不能再叠券
- ❌ **先领店铺券再领国补** → 国补可能因"已用店铺券" 无法激活(政策依赖)
- ❌ **红包过期没用** → 错过红包窗口

正确**领取**顺序:
1. 大促前 1-3 天:领红包口令(京享红包,有效期短)
2. 看准商品 + 核国补资格(云闪付资格码 / 政务平台)
3. 进品类专区领品类券
4. 进商品页/店铺领店铺券
5. 加购物车,凑跨店满减(每满 300-50,需凑到门槛)
6. 结算时**云闪付支付**触发国补 15%
7. PLUS 满减自动计算

## 3. 互斥规则(2026)

### 3-1. 强互斥(系统自动选大的)

| A 券 | B 券 | 互斥结果 |
|---|---|---|
| 商品优惠券 | 店铺优惠券 | **不可叠**,系统自动选优惠大的 |
| 跨店满减 | 店铺自己的满减 | **不可共用**,平台优先 |
| 跨店满减 | 店铺打折活动(如店铺 9 折)| **不可共用**,平台优先 |
| 多张同类型店铺券 | 同 | **只能选一张** |

### 3-2. 弱互斥(部分场景互斥)

| A 券 | B 券 | 互斥规则 |
|---|---|---|
| 国补 | 京东以旧换新补贴 | **某些品类只能选一** |
| 新人券 | 老用户专享券 | 资质互斥(不能同时是新人和老用户) |
| 品类 9 折券 | 店铺 8.5 折活动 | 看商品标签,通常店铺活动优先 |

### 3-3. 完全独立可叠(2026 政策放开)

| A | B | 可叠 |
|---|---|---|
| 京享红包 | 跨店满减 | ✓ |
| 跨店满减 | 国补 | ✓ |
| PLUS 满减 | 跨店满减 | ✓ |
| PLUS 9.5 折 | 国补 | ✓ |
| 跨店满减 | 店铺**优惠券**(不是店铺满减/打折) | ✓ |
| 红包 | 国补 | ✓ |

## 4. PLUS 会员专属规则

**满减阶梯**:
- 满 ¥1000 减 ¥50
- 满 ¥3000 减 ¥100
- 满 ¥5000 减 ¥200
- **家电类**:满 ¥4000 减 ¥300
- 部分品类:叠加 9.5 折

**与国补的关系**:
- PLUS 满减 + 国补 可叠加(两者作用层不同)
- 算法:`(标价 - 红包 - 店铺券 - 跨店 - PLUS满减) × 0.85`

## 5. 国补 15% 政策细则(2026-05)

### 5-1. 适用品类

**数码(单件 ≤ ¥6000)**:
- 手机
- 平板
- 智能手表 / 手环
- 智能眼镜(AR 眼镜 2026 新增)

**家电(单件 ≤ ¥6000 / 部分品类 ≤ ¥8000)**:
- 空调 / 冰箱 / 洗衣机 / 电视(一级能效 ≤ ¥8000)
- 油烟机 / 灶具 / 热水器
- 微波炉 / 烤箱 / 洗碗机

**电脑(2026 全面落地)**:
- 笔记本 / 台式
- 单件价上限不同省

**不在国补内**:
- 鼠标 / 键盘 / 耳机 / 音箱(2026 政策仍未覆盖外设)
- 化妆品 / 服饰 / 食品 / 日用
- 单件价 > ¥6000 的高端机型(超出上限不享)

### 5-2. 补贴金额

- 价格的 15%
- 每位消费者每类产品**补贴 1 件**(数码:手机 1 件 + 平板 1 件 + 手表 1 件 + 眼镜 1 件 = 4 件)
- **每件补贴 ≤ ¥500**(超出 ¥500 部分不补)

实例:
- iPhone 16 ¥5999:补贴 ¥899 → 封顶 ¥500,实补 ¥500
- 小米 13 ¥3000:补贴 ¥450,实补 ¥450
- iPhone 16 Pro ¥7999:**不享国补**(超 ¥6000 上限)

### 5-3. 地区资格

**2026-02 已恢复 23+ 省/直辖市**:
- 北京 / 上海 / 天津 / 重庆 / 广东 / 浙江 / 江苏 / 山东 / 福建 / 四川 / 湖南 / 湖北 等
- 不同省的领取方式不同:
 - **云闪付资格码**(四川 / 山东 / 湖南):云闪付 App 抢券 → 资格码绑定 → 支付自动抵扣
 - **政务平台申领**(部分省):线上填资料 → 1-3 工作日审核 → 资格生效
 - **京东直接领**(部分省):京东 App "数码 588" / "手机 588" 入口直领

**用户必问**:**你是哪个省 / 直辖市?** 不同省政策可能不同,必须核。

## 6. 凑单逻辑(差多少能用更大的券)

### 6-1. 跨店满减凑单算账

实例:**已购商品 ¥499,差 ¥1 能用"满 500 减 50"**

| 选项 | 计算 | 最终实付 |
|---|---|---|
| 不凑单 | ¥499(不享满减) | ¥499 |
| 加 ¥1 凑到 ¥500 | ¥500 - ¥50 满减 = ¥450 | ¥451(含加件)|
| 加 ¥10 凑到 ¥509 | ¥509 - ¥50 = ¥459 | ¥460(含加件 ¥10)|

**结论**:加 ¥1 凑单**省 ¥48**(¥499 - ¥451),**强烈值得**。
加 ¥10 凑单省 ¥39,**也值**(¥10 加件即使丢掉也比直接付 ¥499 划算)。

### 6-2. 凑单"陷阱"识别

**不值的凑单**:
- 加 ¥100 凑满 ¥600 用"满 600 减 50":省 ¥50 - 加 ¥100 = **亏 ¥50**(除非加件本身要买)
- 加 ¥200 凑满 ¥800 用"满 800 减 80":省 ¥80 - 加 ¥200 = **亏 ¥120**

**凑单判断公式**:
```
加件后省的 = 满减额度
加件成本 = 加件价(如果加件你不需要)
凑单值不值 = 满减额度 > 加件成本
```

实例措辞:
> "你要付 ¥499,加 ¥1 凑到 ¥500 能用满减 ¥50 → 加 ¥1 多省 ¥49,值。
> 但加 ¥100 凑满 ¥600 用 ¥50 满减 → 你为了省 ¥50 多花 ¥100,**除非这 ¥100 加件你本来就想买,否则别凑**。"

## 8. 常见踩坑速查

| 踩坑 | 现象 | 怎么避 |
|---|---|---|
| 国补品类不符 | 想给鼠标/耳机用国补,系统不让 | 先核 §5-1 适用品类(只手机/平板/手表/眼镜/家电/电脑) |
| 国补封顶 ¥500 | iPhone 16 算 15% 是 ¥899,实际只补 ¥500 | 单件 ≤ ¥3333 → 国补全额;> ¥3333 → 封顶 ¥500 |
| 单件超 ¥6000 不享 | iPhone 16 Pro ¥7999 没国补 | 数码单件 ≤ ¥6000 才享(部分高端家电 ≤ ¥8000) |
| 凑单亏本 | 加 ¥100 用 ¥50 满减,以为省了 ¥50,实际亏 ¥50 | §6-2 公式判断"加件成本 vs 满减额度" |
| 红包过期 | 大促当天发现红包昨天就过期了 | 大促前 1-3 天领并核有效期 |
| 跨店满减凑反了 | 凑 ¥1000 用 -¥100,但多凑的件是凑不需要的 | 凑单时只凑"本来就要买" 的件 |
| 店铺券与跨店冲 | 用了店铺自己的满减,失去跨店满减资格 | 优先用跨店满减(平台级,力度大) |
| PLUS 满减门槛错估 | 商品 ¥1000 但满 1000 减 50 不触发 | 满 ¥1000 ≠ "总价 ≥ ¥1000",看的是 PLUS 专享商品的合计 |

## 9. 大促期特殊规则(2026 618 / 双 11)

### 9-1. 跨店满减升级

大促期"每满 300 减 50" 升级为"每满 300 减 60" 或"每满 600 减 100" 等更大力度。**自动叠加,不需要手动领**。

### 9-2. 京享红包加大

平时红包 ¥5-50,大促期红包 ¥50-200 甚至 ¥500。**大促前 3-7 天每日可抢**,**每日上限**(每个账号每天 1-3 个红包)。

### 9-3. 国补窗口

大促期国补可能与平台券**共同生效**,部分省份在大促期国补额度翻倍(¥500 → ¥1000)。**必须实时核当天政策**。

### 9-4. 时点选择

**618 最便宜时段**(基于 2025 历史):
- 5 月 31 日 20:00 (预售开启)
- 6 月 17 日 20:00 - 6 月 18 日 24:00(主战场)
- 6 月 18 日 23:00 - 23:59(最后一小时,部分品类降价)

**双 11 最便宜时段**(基于 2025 历史):
- 10 月 31 日 20:00(第一波)
- 11 月 10 日 20:00 - 11 月 11 日 24:00(主战场)
- 11 月 11 日 22:00 - 23:59(最后两小时)
