**作用**:被 `SKILL.md` 的 Step 2(Platform Detect)+ Step 3/4 Read。**拼多多券规则跟京东自营完全不同**,本文件单独处理。

**核心**:拼多多 = "**百亿补贴 + 平台券 + 红包 + 限时秒杀**" 四件套,**没有京东那种 PLUS 阶梯满减**,**百亿补贴不能叠国家补贴 15%**(完全是两件事)。

---

## 1. 拼多多 — 4 类优惠概览

| 类型 | 典型力度 | 触发方式 | 关键限制 |
|---|---|---|---|
| **百亿补贴** | ¥10-3000(看商品)| 平台自动 — 商品页底部红框 + Logo | 仅"百亿补贴"标识商品,价格本身就含 |
| **平台券** | ¥5-200 | 商品页 / "我的-优惠券" 领 | 全店 / 全品类常无门槛 |
| **红包** | ¥1-50 | 大促前抢 / 任务发(签到 / 拼小圈)| 有效期短(1-3 天)|
| **限时秒杀** | 短窗口超低价 | 整点 / 半点 自动触发 | 限秒杀时段 + 限量 |

**附加**:
- **新人券 / 砍价免费拿 / 多多果园**:限新用户 / 任务社交,不是常规叠加范畴
- **VIP / 月卡**:会员特权价模型,不是阶梯满减(跟京东 PLUS 不同)

## 2. 跟京东自营的关键差异

| 维度 | 京东自营 | 拼多多 |
|---|---|---|
| **平台补贴形式** | 国家补贴 15%(政策驱动)| 百亿补贴(平台自掏,自 2019)|
| **是否享国补 15%** | ✓ 数码 / 家电 / 电脑 ≤ ¥6000 适用 | ✗ **绝大多数百亿补贴商品不享** |
| **PLUS 满减** | 满 1000 减 50 / 满 5000 减 200 阶梯 | ✗ **无** |
| **跨店满减** | 大促期"每满 300 减 50" | ✗ **无**(拼多多走单店 / 单商品逻辑)|
| **店铺券** | 商品 / 店铺券,与跨店互斥 | 平台券为主,店铺券较少 |
| **大促节奏** | 618 / 双 11 集中爆发 | **全年常态低价** + 限时秒杀 + 大促 |
| **真假货风险** | 自营 ~100% / 第三方差异 | 百亿补贴 95% / 普通店铺差异大 |
| **售后流程** | 自营当日达 / 极速退款 | 平台介入,退货物流 5-7 天 |

## 3. 拼多多 叠加顺序

**简单很多**(没有京东那么多层级):

```
百亿补贴价(基础,平台直接补贴后的价)
  ↓ 减平台券(用户领的)
  ↓ 减红包
  ↓ 限时秒杀进一步降(如果商品在秒杀时段)
  = 最终实付
```

**注意**:
- **百亿补贴价**就是该商品对你显示的"现价",**不是原价**
- 平台券 + 红包通常可叠(不强互斥)
- 限时秒杀触发后,叠加是基于秒杀价

### 4-1. 强互斥(系统自动)

| A | B | 互斥 |
|---|---|---|
| 多张同类平台券 | | 只能用 1 张(系统选大的) |
| 新人券 | 老用户 | 资质互斥 |

### 4-2. 弱互斥(看商品)

| A | B | 处理 |
|---|---|---|
| 百亿补贴价 | 部分店铺券 | 看店铺规则,有些店铺券能叠 |
| 红包 | 限时秒杀价 | 通常能叠 |
| 平台券 | 多多月卡 / VIP 价 | 看页面提示 |

**经验法则**:拼多多券互斥规则**经常变 + 平台不公开完整规则**,**最稳的做法是结算时看实际抵扣**。

## 5. 真假货风险识别

**底部红框 + "百亿补贴" Logo** = 关键身份标识。

| 标识 | 真品概率 | 备注 |
|---|---|---|
| **底部红框 "百亿补贴"** | ~95%+ | 平台背书 + 商家保证金 + 假一赔十 |
| **店铺名带"官方旗舰店" + 蓝 V** | ~95%+ | 品牌官方授权 |
| **店铺名"海外旗舰店" + 进口溯源码** | ~95%+ | 跨境保税仓 |
| 普通店铺 + 高销量(>1万)+ 高评分(4.7+)| 85-95% | 看具体商品 |
| 普通店铺 + 低销量 / 低评分 | 50-80% | **警惕** |
| 个人卖家 / 闲鱼似的 | 30-60% | **强烈警惕** |

**验真方法**:
- 收货立刻看包装防伪码 / 批号
- iPhone 类:序列号 `apple.com.cn/checkcoverage` 查激活状态
- 美妆类:防伪码 + checkfresh.com 查生产日期 + 保质期
- 截图 / 视频拆箱(如有问题用作维权证据)

## 6. 拼多多特殊场景

### 6-1. 拼单 vs 单独购买

拼多多大多商品有"拼单价" 和"单独购买价"两个价。

- **拼单价**:跟陌生人凑够 2-3 人成团,通常便宜 10-30%
- **单独购买**:不用等成团,但价高
- **"百亿补贴" 商品**:多数已经是平台补贴后的拼单价,无需凑团

### 6-2. 限时秒杀(整点 / 半点)

- 通常 30 分钟或 1 小时窗口
- 限量(几百到几千件)
- 抢到就走平台秒杀价
- 错过 → 回到日常价

### 6-3. 直播间专享(拼多多版)

- 拼多多有直播频道但不如抖音强
- 偶尔头部品牌做拼多多专场,价格深降
- 看到"直播间专享" 标识可入,但少见

## 7. 实例

### 实例 1 — SK-II 神仙水(美妆海淘)

**输入**:拼多多看到 SK-II 神仙水 230ml 双瓶装 ¥1289(¥644.5/瓶),百亿补贴标识。

**判断**:
- ✓ **百亿补贴 + 海外旗舰店**:真品概率 95%+
- 价格分析:京东自营单瓶 ¥1558,拼多多 ¥644.5 = 0.41× = 保税仓正常区间(参考 cosmetics judgment 渠道差倍数)
- **不能叠国补**(美妆不在国补品类内)
- **可买**,收货验防伪码

**操作步骤**:
1. 商品页确认 "百亿补贴" 红框 + "海外旗舰店" + 进口溯源码
2. 看是否有平台券可领(通常无门槛)
3. 红包(大促前可抢)
4. 直接付款(无需 PLUS 类会员)
5. 收货立刻验防伪码

### 实例 2 — iPhone 16 Pro(警惕渠道掉档)

**输入**:拼多多看到 iPhone 16 Pro 256G ¥6299,vs 京东自营 ¥7999。

**判断**:
- 看是否"百亿补贴" 标识 → **必看**
- 是百亿补贴 → 差价 21.3%,**仍要警惕**(超过常规渠道差 5-15%)
- 看店铺类型:**是 Apple 官方旗舰店还是第三方**?
- 普通店铺 + 差价 21% → 港版 / 激活机 / 翻新 风险高
- 百亿补贴 + 看似正品 → 收货立刻查序列号

**操作步骤**:
1. **首要**:确认百亿补贴 + 店铺类型
2. 不是百亿补贴 → **强烈不建议**
3. 是百亿补贴 → 看是否官方旗舰
4. 收货立刻 `apple.com.cn/checkcoverage` 查序列号
5. 序列号已激活 = 激活机 / 官换机,**7 天无理由退**
