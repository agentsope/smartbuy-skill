# prediction-rules.md — 预测算法 + 置信度判定

> ⏱️ **DATA-TIMESTAMP**: 2026-05-29 — 内置规则/价格/政策按此时点;**6 个月内有效**,过期建议 WebSearch 重新验证当前政策。

**作用**:被 `SKILL.md` 的 Step 4(Predict)Read。把"N 个历史时点"翻成"下次大促大概率 ¥X-Y"。

**核心**:**预测永远是区间不是单点**,且必须标置信度。不允许"拍脑袋猜"。

---

## 1. 算法骨架

### Step A:计算"大促降幅率"

对每个历史大促时点,算:

```
大促降幅率 = 大促价 / 同期平时价
```

实例(罗技 MX Master 3S):
- 平时价 ~¥469 (2026-05 京东日常)
- 2025-11.11 大促价 ¥348 → 降幅率 = 348 / 469 = **0.742**(74.2%,即 7.4 折)
- 2024-06 大促价 ¥299(限量,**不计入**) — 见 §3 处理
- 2025-03 国补底 ¥362 → 降幅率 = 362 / 469 = **0.772**(7.7 折)
- 2025-10 国补底 ¥366 → 降幅率 = 366 / 469 = **0.780**(7.8 折)

### Step B:计算降幅均值 + 标准差

降幅率样本:`[0.742, 0.772, 0.780]`
- **均值** = (0.742 + 0.772 + 0.780) / 3 = **0.765**
- **标准差** ≈ 0.020(粗略计算)

### Step C:预测区间

**下次大促价区间** = 当前价 × (均值 ± 1 标准差):
- 中位:¥499 × 0.765 = ¥381.7
- 下限:¥499 × (0.765 - 0.020) = ¥372
- 上限:¥499 × (0.765 + 0.020) = ¥391

**预测区间**:**¥372-391**(大概率)

但!**还要看历史最低**:历史曲线已经出现过 ¥348,**预测最低不能高于历史最低** → 区间下限可下探到 ¥348。

**最终预测**:**¥348-391**(大概率)

### Step D:置信度评定

见 §4。

## 2. 当前价的"平时价" 确定

**问题**:用户给的"当前价 ¥499" 是不是"平时价"?

判断:
- 如果当前价 = 京东自营基础活动价(无大促)→ 是平时价
- 如果当前价 = 大促预热价(临近 618 / 双 11)→ **不是平时价**,要倒推
- 如果当前价含 PLUS / 凑券 / 国补 → **不是裸价**,要剥离

**怎么剥离**:
- "你这个价含国补吗" → 让用户确认
- 含国补:`平时价 = 当前价 / 0.85`(国补 15%)
- 含 PLUS 满 ¥1000-50:`平时价 = 当前价 + ¥50`
- 含京享红包 ¥20:`平时价 = 当前价 + ¥20`

如果用户搞不清,直接用 WebSearch 抓近期"非大促期" 报道的基础价(如"近 30 天京东自营常态价")作为锚点。

## 3. 数据点处理规则

### 3-1. 限量秒杀价**不计入常规预测**

特征:
- 报道明说"限量 X 台" / "20:00 准点抢" / "前 200 名"
- 价格远低于其他时点(往往低 30-50%)

**处理**:
- **不计入** 降幅率样本
- 但在输出时**标注**"历史曾出现 ¥X 限量秒杀,但绝大多数人抢不到,**不作为预测锚点**"
- 实例:罗技 ¥299 限量,常规预测用 ¥348

### 3-2. "上一代" 限量清仓价**不可外推**

特征:
- 产品已被新一代取代,旧款进入"清库存" 阶段
- 价格断崖式下降(跌 30%+)

**处理**:
- **预测置信度降级**(从高 → 中)
- 必须输出"末代换代风险" 提示
- 实例:罗技 MX Master 3S 现在是末代,新一代 MX Master 4 已发 → 大促可能更激进清仓 **或** 直接停产 → 预测区间扩大

### 3-3. 政策驱动的数据点(国补、新人券)

特征:
- 大幅降价来自一次性政策(国补 / 新人券)
- 政策可能下次大促不再有

**处理**:
- 计入样本,但置信度降低
- 标注"X 时点的 ¥Y 是国补叠加价,2026 国补政策仍存,但可能退坡"

## 4. 置信度判定

| 等级 | 标准 | 输出措辞 |
|---|---|---|
| **高置信** | ≥ 3 个常规大促时点 + 标准差 < 5% + 无末代换代风险 | "大概率 ¥X-Y,**置信度高**" |
| **中置信** | 2-3 个时点 / 或离散度 5-15% / 或有 1 个风险 | "可能 ¥X-Y,**置信度中**,风险:[列出来]" |
| **低置信** | < 2 个时点 / 离散度 > 15% / 多个风险叠加 / 末代 | "不太确定 ¥X-Y,**置信度低**,**建议大促前 1 周再问一次**" |
| **拒绝预测** | 0-1 个时点 / 新品 < 6 个月 / 已停产 | "**数据不足,不预测**" 退路 |

---

## 5. 风险点清单

预测必须**列出风险**,绝不写"双 11 ¥X" 不带任何提示。

### 5-1. 末代换代风险

特征:新一代已发或即将发
影响:大促可能更深降幅 **或** 直接停产
措辞:"⚠️ {新一代} 已于 {日期} 发布,这款是末代清库存 → 大促可能比预测更激进(清完为止) **或** 没货(下架)"

### 5-2. 国补退坡风险

特征:国补政策依赖,品类/省份资格可能变
影响:大促价 = 平时价 - 国补,国补退则大促可能变贵
措辞:"⚠️ 预测含国补假设,2026 国补政策动态调整,大促当周以最新政策为准"

### 5-3. 限量风险

特征:历史大促价多数是"限量 X 台 20:00 抢"
影响:大多数用户抢不到,真实到手价更高
措辞:"⚠️ 历史 ¥X 是限量价,常规可买价是 ¥Y(取常规)"

### 5-4. 数据时效风险

特征:历史时点都是 > 12 个月前
影响:行业变化大,旧规律可能失灵
措辞:"⚠️ 历史数据多在 12 个月前,行业变化(如直播带货 / 新平台补贴) 可能让旧规律失灵"

### 5-5. 平台迁移风险

特征:历史大促低价多在 A 平台(如京东),用户现在看 B 平台(如拼多多)
影响:不同平台规则不同,跨平台预测不准
措辞:"⚠️ 历史低价多在京东自营,你看的拼多多走百亿补贴规则,不能直接套预测"

## 6. 输出模板

### 模板 1 — 高置信 + 老品

> **双 11 大概率 ¥X-Y 区间**(置信度高)。
>
> 历史一句话:近 2 年大促底 ¥X(2024-11、2025-11.11),降幅率均值 0.XX,标准差 < 5%。
>
> **建议**:等大促,大概率比现在省 ~XX%。

### 模板 2 — 中置信 + 有风险

> **双 11 可能 ¥X-Y 区间**(置信度中)。
>
> 历史 2 个时点支持,但 ⚠️ {风险 1}{风险 2}。
>
> **建议**:如果不急 → 等;如果急 → 现在买不亏。大促前 1 周再问一次。

### 模板 3 — 低置信 + 末代

> **双 11 不太确定,可能 ¥X-Y 之间**(置信度低)。
>
> ⚠️ 这款是末代清库存,大促可能:
> - 比预测更激进(全部清完)→ ¥{下限更低} 也可能
> - 直接停产 / 下架 → 你想买都买不到
>
> **建议**:**不要赌大促** → 现在 ¥XXX 已经算可入,趁有货拿下。

### 模板 4 — 拒绝预测

> **不预测**:你这个商品我只能拿到 0-1 个历史时点(新品 / 数据不足)。
>
> 替代信号:用 `price-detective` 看**当前折扣率** —— 现在 ¥X 是官网原价的 Y%,如果 Y < 90% 已经算好价。新品大促的降幅通常 5-15%,你按这个区间预判。
>
> 过去 1 个大促后再来问我,那时我就有 ≥ 3 个历史时点能真预测。

## 7. 常见错误(自查)

| 错误 | 怎么避 |
|---|---|
| 给单点预测"双 11 ¥350" | 改成区间 "¥X-Y" |
| 忽略限量秒杀,用 ¥299 作锚 | §3-1 排除限量价 |
| 忘标"不保证" | 结尾必标 |
| 用 2024 数据预测 2026 | 检查时效,> 12 月数据标风险 |
| 把"政策驱动" 当"市场规律" | 标"国补依赖" 风险 |
| 漏掉末代换代 | §3-2 + Step 5-1 必查 |
| 数据 < 3 个还硬预测 | §4 直接拒绝 |

---

*预测是辅助决策,不是确定性。任何预测都要标"不保证 + 大促前再问"。*
